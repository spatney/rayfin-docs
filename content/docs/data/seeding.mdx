---
title: Seeding data
description: Populate a Rayfin database with development data using RayfinClient in a Node.js script.
---

Use `RayfinClient` from a plain Node.js script to populate development or test data — the
same client and the same `client.data.<Entity>` calls you use from your frontend, just run
with `tsx` instead of in a browser.

## Write the seed script

Read the backend URL and publishable key from `rayfin/.env` (generated by `rayfin up`)
rather than hardcoding them — the port and key vary per project and per deployment.

```typescript title="scripts/seed.ts"
import { readFileSync } from 'fs';
import { RayfinClient } from '@microsoft/rayfin-client';
import type { AppSchema } from '../rayfin/data/schema';

function loadEnv(): Record<string, string> {
  const vars: Record<string, string> = {};
  for (const line of readFileSync('rayfin/.env', 'utf-8').split('\n')) {
    const match = line.match(/^([^#=]+)=(.+)$/);
    if (match) vars[match[1].trim()] = match[2].trim();
  }
  return vars;
}

const env = loadEnv();
const client = new RayfinClient<AppSchema>({
  baseUrl: env['RAYFIN_PUBLIC_API_URL'],
  publishableKey: env['RAYFIN_PUBLIC_PUBLISHABLE_KEY'],
  authStorage: false, // no localStorage in Node.js
});

async function seed() {
  // Email/password auth works for local development seeding only —
  // deployed Fabric apps use Entra SSO exclusively.
  try {
    await client.auth.signUp({ email: 'admin@example.com', password: 'Admin123!' });
  } catch {
    // user may already exist from a previous seed run
  }
  await client.auth.signIn({ email: 'admin@example.com', password: 'Admin123!' });
  const session = client.auth.getSession();
  if (!session.isAuthenticated || !session.user) {
    throw new Error('Seed sign-in failed.');
  }

  // Create parent records first, then children that reference their IDs.
  const notebook = await client.data.Notebook.create({
    name: 'Work',
    isDefault: true,
    createdAt: new Date(),
    user_id: session.user.id,
  });

  await client.data.Note.create({
    title: 'First note',
    content: 'Hello world',
    createdAt: new Date(),
    notebook: { id: notebook.id },
    user_id: session.user.id,
  });
}

seed().catch(console.error);
```

Run it with `tsx`:

```bash
npx tsx scripts/seed.ts
```

Or wire it into `package.json` for a shorter command:

```json title="package.json"
{
  "scripts": {
    "seed": "tsx scripts/seed.ts"
  }
}
```

```bash
npm run seed
```

## Key rules

- **Read `baseUrl` and `publishableKey` from `rayfin/.env`**, not hardcoded values — they
  vary per project and change on every deploy.
- **Set `authStorage: false`.** `RayfinClient` auto-detects Node.js and falls back to
  memory-only session storage even without this, but setting it explicitly makes the
  intent clear and avoids relying on the auto-detection.
- **Create parents before children.** A `@one()` relationship needs the parent's `id` to
  exist first — create the `Notebook` before the `Note` that references it, as shown
  above. See [Relationships](/docs/data/relationships) for how `@one()` / `@many()` work.
- **Email/password sign-in is local-development only.** Deployed Fabric apps accept only
  Fabric SSO (Entra ID) — a seed script using `signUp` / `signIn` like the one above only
  works against a local backend.

## Seeding a single entity

For an entity with no relationships, the script is shorter — sign in, then create:

```typescript title="scripts/seed-todos.ts"
import { readFileSync } from 'fs';
import { RayfinClient } from '@microsoft/rayfin-client';
import type { AppSchema } from '../rayfin/data/schema';

function loadEnv(): Record<string, string> {
  const vars: Record<string, string> = {};
  for (const line of readFileSync('rayfin/.env', 'utf-8').split('\n')) {
    const match = line.match(/^([^#=]+)=(.+)$/);
    if (match) vars[match[1].trim()] = match[2].trim();
  }
  return vars;
}

const env = loadEnv();
const client = new RayfinClient<AppSchema>({
  baseUrl: env['RAYFIN_PUBLIC_API_URL'],
  publishableKey: env['RAYFIN_PUBLIC_PUBLISHABLE_KEY'],
  authStorage: false,
});

async function seed() {
  try {
    await client.auth.signUp({ email: 'admin@example.com', password: 'Admin123!' });
  } catch {
    /* user may already exist */
  }
  await client.auth.signIn({ email: 'admin@example.com', password: 'Admin123!' });
  const session = client.auth.getSession();
  if (!session.isAuthenticated || !session.user) {
    throw new Error('Seed sign-in failed.');
  }

  const titles = ['Write the changelog', 'Review PR #42', 'Ship the release'];
  for (const title of titles) {
    await client.data.Todo.create({
      title,
      isCompleted: false,
      createdAt: new Date(),
      user_id: session.user.id,
    });
  }
}

seed().catch(console.error);
```
