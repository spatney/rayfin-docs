---
title: Seeding data
description: Populate a Rayfin database with development data using RayfinServerClient in a Node.js script.
---

Use `RayfinServerClient` from a plain Node.js script to populate development or test
data — the same `client.data.<Entity>` calls you use from your frontend, just run with
`tsx` instead of in a browser, and authenticated with a supplied access token instead of a
browser session.

## Write the seed script

Read the backend URL and publishable key from `rayfin/.env` (generated by `rayfin up`)
rather than hardcoding them — the port and key vary per project and per deployment.

```typescript title="scripts/seed.ts"
import { readFileSync } from 'fs';
import { RayfinServerClient } from '@microsoft/rayfin-client';
import type { AppSchema } from '../rayfin/data/schema';

function loadEnv(): Record<string, string> {
  const vars: Record<string, string> = {};
  for (const line of readFileSync('rayfin/.env', 'utf-8').split('\n')) {
    const match = line.match(/^([^#=]+)=(.+)$/);
    if (match) vars[match[1].trim()] = match[2].trim();
  }
  return vars;
}

const env = loadEnv();
const client = new RayfinServerClient<AppSchema>({
  baseUrl: env['RAYFIN_PUBLIC_API_URL'],
  publishableKey: env['RAYFIN_PUBLIC_PUBLISHABLE_KEY'],
  // A Node.js script can't drive the browser-based Fabric SSO flow itself — supply a
  // token from a session your app already established. See "Key rules" below.
  accessToken: process.env.RAYFIN_SEED_ACCESS_TOKEN,
});

async function seed() {
  const userId = process.env.RAYFIN_SEED_USER_ID;
  if (!userId) {
    throw new Error('Set RAYFIN_SEED_USER_ID to the id of the user the seed data belongs to.');
  }

  // Create parent records first, then children that reference their IDs.
  const notebook = await client.data.Notebook.create({
    name: 'Work',
    isDefault: true,
    createdAt: new Date(),
    user_id: userId,
  });

  await client.data.Note.create({
    title: 'First note',
    content: 'Hello world',
    createdAt: new Date(),
    notebook: { id: notebook.id },
    user_id: userId,
  });
}

seed().catch(console.error);
```

Run it with `tsx`:

```bash
npx tsx scripts/seed.ts
```

Or wire it into `package.json` for a shorter command:

```json title="package.json"
{
  "scripts": {
    "seed": "tsx scripts/seed.ts"
  }
}
```

```bash
npm run seed
```

## Key rules

- **Read `baseUrl` and `publishableKey` from `rayfin/.env`**, not hardcoded values — they
  vary per project and change on every deploy.
- **Use `RayfinServerClient`, not `RayfinClient`.** It skips the browser-coupled `Auth`
  module and takes a pre-acquired `accessToken` instead — the right shape for a script
  that can't run a browser-based sign-in flow. See
  [`@microsoft/rayfin-client`](/docs/reference/sdk/rayfin-client#rayfinserverclient).
- **Supply a valid access token for entities that require authentication.** Fabric SSO
  signs a user in through a browser popup or the Fabric portal iframe, which a Node.js
  script can't drive itself. Pass a token from a session your app already established —
  for example, through an environment variable your shell or CI pipeline sets — rather
  than attempting to sign in from the script.
- **Create parents before children.** A `@one()` relationship needs the parent's `id` to
  exist first — create the `Notebook` before the `Note` that references it, as shown
  above. See [Relationships](/docs/data/relationships) for how `@one()` / `@many()` work.

## Seeding a single entity

For an entity with no relationships, the script is shorter — just create:

```typescript title="scripts/seed-todos.ts"
import { readFileSync } from 'fs';
import { RayfinServerClient } from '@microsoft/rayfin-client';
import type { AppSchema } from '../rayfin/data/schema';

function loadEnv(): Record<string, string> {
  const vars: Record<string, string> = {};
  for (const line of readFileSync('rayfin/.env', 'utf-8').split('\n')) {
    const match = line.match(/^([^#=]+)=(.+)$/);
    if (match) vars[match[1].trim()] = match[2].trim();
  }
  return vars;
}

const env = loadEnv();
const client = new RayfinServerClient<AppSchema>({
  baseUrl: env['RAYFIN_PUBLIC_API_URL'],
  publishableKey: env['RAYFIN_PUBLIC_PUBLISHABLE_KEY'],
  accessToken: process.env.RAYFIN_SEED_ACCESS_TOKEN,
});

async function seed() {
  const userId = process.env.RAYFIN_SEED_USER_ID;
  if (!userId) {
    throw new Error('Set RAYFIN_SEED_USER_ID to the id of the user the seed data belongs to.');
  }

  const titles = ['Write the changelog', 'Review PR #42', 'Ship the release'];
  for (const title of titles) {
    await client.data.Todo.create({
      title,
      isCompleted: false,
      createdAt: new Date(),
      user_id: userId,
    });
  }
}

seed().catch(console.error);
```
