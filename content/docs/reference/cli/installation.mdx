Install the Rayfin CLI in the project that owns `rayfin/rayfin.yml`. A local dev dependency
keeps the CLI version aligned with the rest of the Rayfin packages.

## Prerequisites

- Node.js 20 or later.
- npm 10 or later.

## New project

```bash
npm create @microsoft/rayfin@latest my-app
cd my-app
```

The create wrapper scaffolds a project and installs `@microsoft/rayfin-cli` as a dev
dependency.

## Existing project

```bash
npm install --save-dev @microsoft/rayfin-cli
npx rayfin init
```

Run `npx rayfin init` from the directory that should contain `rayfin/rayfin.yml`.

## Run a specific CLI version without installing

```bash
npx @microsoft/rayfin-cli@2.0.0 --version
```

Inside a project with `@microsoft/rayfin-cli` installed, prefer `npx rayfin <command>` so
npm resolves the local project version.

## Verify the installation

```bash
npx rayfin --version
npx rayfin --help
```

The help output should show the visible 2.0 command groups: `init`, `dev`, `up`,
`secret`, `functions`, `connector`, `env`, `login`, `logout`, `docs`, `storage`, and
`telemetry`. `storage` and `telemetry` are new in 2.0.
[New in 2.0](/docs/reference/changelog#rayfin-20)

## Update the CLI

```bash
npm install --save-dev @microsoft/rayfin-cli@latest
npm install
npx rayfin --version
```

Rayfin packages ship in lockstep. When you update the CLI, update the other
`@microsoft/rayfin-*` dependencies in the same change. Moving from 1.x to 2.0 also changes
client code; see the [changelog](/docs/reference/changelog) before you upgrade.

## First commands

```bash
npx rayfin login
npm run dev
npx rayfin up
```

`npm run dev` in bundled templates runs `rayfin dev`; it does not publish static content.
