Use `@microsoft/rayfin-cli` from a Rayfin project root to scaffold projects, run the local
Fabric-backed development session, deploy to Microsoft Fabric, and query version-locked
Rayfin documentation. The binary is `rayfin`; scaffolded projects call it through
`npx rayfin` or package scripts.

## Typical workflow

```bash
npm create @microsoft/rayfin@latest my-app
cd my-app
npx rayfin login
npm run dev
npx rayfin up
```

`npm run dev` in the bundled templates runs `rayfin dev`, which prepares the Fabric
backend and starts the local frontend. Use `rayfin up` when you want to deploy static
content and Functions to Fabric.

## Root options

These options are declared on the root `rayfin` program.

| Option | Default | Description |
| --- | --- | --- |
| `-V, --version` | — | Output the version number. |
| `-y, --yes` | `false` | Auto-accept all confirmation prompts. |
| `--output <mode>` | — | Output format for the invoked subcommand. Choices: `interactive`, `plain`, `json`. |
| `--verbose` | `false` | Enable verbose output for the invoked subcommand. |
| `--json` | `false` | Emit machine-readable JSON output from the invoked subcommand. |
| `-h, --help` | — | Display help for `rayfin` or a subcommand. |

Many subcommands redeclare `--json`, `--verbose`, or `-y, --yes` so they also work after
the subcommand name.

## Visible commands

| Command | Purpose |
| --- | --- |
| [`init`](/docs/reference/cli/init) | Create a new Rayfin project, add Rayfin to an existing directory, list templates, or manage agent files. |
| [`dev`](/docs/reference/cli/dev) | Start a local development session against a Fabric Rayfin backend. |
| [`up`](/docs/reference/cli/up) | Deploy the application to Fabric as a Rayfin item. |
| [`secret`](/docs/reference/cli/secret) | Manage secrets for deployed Rayfin items. [Changed in 1.36](/docs/reference/changelog#rayfin-136) |
| [`functions`](/docs/reference/cli/functions) | Manage Rayfin Functions. [Changed in 1.36](/docs/reference/changelog#rayfin-136) |
| [`connector`](/docs/reference/cli/connector) | Manage external data connectors. [Changed in 1.36](/docs/reference/changelog#rayfin-136) |
| [`env`](/docs/reference/cli/env) | Emit framework-specific `.env.local` values from `rayfin/.env`. |
| [`login`](/docs/reference/cli/login) | Sign in to the Rayfin platform. |
| `logout` | Sign out and clear cached credentials; see [Login](/docs/reference/cli/login). |
| [`docs`](/docs/reference/cli/docs) | Query Rayfin docs from installed packages, or discover packages not yet installed. |
