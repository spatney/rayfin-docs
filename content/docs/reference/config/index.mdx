description: Reference for Rayfin project configuration, environment variables, and rayfin.yml interpolation in Rayfin 1.36.2.
---

Rayfin projects are configured with committed `rayfin/rayfin.yml` and local environment
files. Use this section when you need the exact keys a CLI or agent can edit.

- [rayfin.yml reference](/docs/reference/config/rayfin-yml) — complete schema for services,
  connectors, secrets, and deployment-related settings.
- [Environment variables](/docs/reference/config/environment-variables) — public frontend
  variables, CLI overrides, feature flags, telemetry variables, and file locations.
- [Environment variable interpolation](/docs/reference/config/env-interpolation) — `${VAR}`
  and `${VAR:-default}` inside `rayfin.yml`.

```prompt title="Audit Rayfin configuration"
Read rayfin/rayfin.yml, rayfin/.env.example, and package.json in my Rayfin project. Tell me
which Rayfin services are enabled, which environment variables are required, and whether
any 1.36-only settings need a package upgrade.
```
