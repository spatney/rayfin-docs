This section is exhaustive, precise detail rather than task-first guidance — reach for it
when you need an exact flag, option, signature, or error message rather than an explanation
of how a feature works. If you're learning a concept for the first time, the
[Data](/docs/data), [Auth](/docs/auth), or [Deploy](/docs/deploy) guides are a better
starting point.

## In this section

- **[Changelog](/docs/reference/changelog)** — what changed in each release these docs cover,
  the meaning of the version tags, and step-by-step upgrade instructions.
- **[CLI](/docs/reference/cli)** — every `rayfin` command, subcommand, and flag.
- **[Configuration](/docs/reference/config)** — the `rayfin.yml` schema and every
  environment variable the CLI and runtime read or write.
- **[SDK](/docs/reference/sdk)** — API reference for every `@microsoft/rayfin-*` package:
  decorators, client construction, the query API, auth, connectors, and app state.
- **[Rules for coding agents](/docs/reference/agent-rules)** — the condensed do/don't list
  for generating Rayfin code that works.
- **[Known limitations](/docs/reference/known-limitations)** — current constraints in
  service availability, functions, connectors, the data client, DAB, relationships, auth,
  and schema apply, each with a workaround.
- **[Deprecations](/docs/reference/deprecations)** — what recent releases deprecated or
  removed and what to use instead, plus how to silence deprecation warnings.
- **[Errors](/docs/reference/errors)** — a symptom → cause → fix index gathered from every
  troubleshooting section in the guide.

> [!TIP]
> Check [Known limitations](/docs/reference/known-limitations) before generating entities,
> queries, or permission decorators — several common mistakes (missing `@text()` length,
> missing permission decorators, `findByPk` instead of `findById`) are constraints, not
> bugs, and are documented there with the correct pattern.

## Package overview

Every package that ships as part of Rayfin 2.0.0. All of them share one version number —
install them at the same exact version.

| Package | Kind | What it does |
| --- | --- | --- |
| [`@microsoft/rayfin-core`](/docs/reference/sdk/rayfin-core) | SDK | Code-first decorators for data model and storage folder definition. The CLI reads this metadata to generate Data API Builder and storage configuration. |
| [`@microsoft/rayfin-data`](/docs/reference/sdk/rayfin-data) | SDK | `dataService()` and the data client for querying, mutating, and aggregating entities through the generated GraphQL endpoint. |
| [`@microsoft/rayfin-client`](/docs/reference/sdk/rayfin-client) | SDK | `RayfinClient.create`, which composes auth and the services you register into one client, plus `suppliedToken()` and runtime config loading. |
| [`@microsoft/rayfin-auth`](/docs/reference/sdk/rayfin-auth) | SDK | `browserSession()` and session and token management for Rayfin apps. |
| [`@microsoft/rayfin-auth-provider-fabric`](/docs/reference/sdk/rayfin-auth-provider-fabric) | SDK | Microsoft Entra sign-in through Fabric SSO, plus direct Entra token sign-in. |
| [`@microsoft/rayfin-embed-host`](/docs/reference/sdk/rayfin-embed-host) | SDK | Parent-page host that signs an embedded Rayfin app in with your portal's Entra token. |
| [`@microsoft/rayfin-app-state-fabric`](/docs/reference/sdk/rayfin-app-state-fabric) | SDK | Deep-link application state for apps embedded in the Fabric portal. |
| [`@microsoft/rayfin-functions`](/docs/reference/sdk/rayfin-functions) | SDK | `functionsService()` and the client-side surface for invoking functions, behind `client.functions`. |
| [`@microsoft/fabric-user-data-functions`](/docs/functions/writing-functions) | SDK | Function authoring surface: `udf.func()`, `RayfinContext`, `AudienceType`, and the typegen behind `types.ts`. |
| [`@microsoft/rayfin-storage`](/docs/reference/sdk/rayfin-storage) | SDK | `storageService()` and the typed file storage client, behind `client.storage`. |
| [`@microsoft/rayfin-telemetry`](/docs/reference/sdk/rayfin-telemetry) | SDK | Browser telemetry initialization for the app's Application Insights resource. Experimental. |
| [`@microsoft/rayfin-connectors`](/docs/reference/sdk/rayfin-connectors) | SDK | `connectorsService()` and the typed connector runtime behind `client.connectors`, plus `Source` and `AutoGenerated` for connector entities. |
| [`@microsoft/rayfin-connector-fabric-graphql`](/docs/reference/sdk/rayfin-connector-fabric-graphql) | SDK | `GraphQLBackedConnector` marker for warehouse, SQL database, and Lakehouse SQL connectors. |
| [`@microsoft/rayfin-connector-fabric-semanticmodel`](/docs/reference/sdk/rayfin-connector-fabric-semanticmodel) | SDK | Semantic model connector: DAX through `executeQuery`. |
| [`@microsoft/rayfin-connector-fabric-iq-mcp`](/docs/reference/sdk/rayfin-connector-fabric-iq-mcp) | SDK | Fabric IQ connector: natural-language questions over Power BI data through MCP. |
| [`@microsoft/rayfin-connector-eventhouse`](/docs/reference/sdk/rayfin-connector-eventhouse) | SDK | Eventhouse (KQL database) connector for existing connectors, formerly `@microsoft/rayfin-connector-kusto`. New ones cannot be added in 2.0. |
| [`@microsoft/rayfin-lib`](/docs/reference/sdk/rayfin-lib) | SDK | Shared HTTP transport, errors, and client-composition types used by every other Rayfin SDK. |
| [`@microsoft/rayfin-cli`](/docs/reference/cli) | Tool | Command-line interface: scaffolding, the development loop, deployment, and the `rayfin docs` command group. |
| [`@microsoft/rayfin-local-dev`](/docs/start/develop-locally) | Tool | Vite adapter used by `rayfin dev`: same-origin routing to the backend and local Functions, and local sign-in. |
| [`@microsoft/create-rayfin`](/docs/start/quickstart) | Tool | Project scaffolding behind `npm create @microsoft/rayfin@latest`. |
| [`@microsoft/rayfin-mcp`](/docs/reference/cli/docs#mcp-server) | Tool | Model Context Protocol server exposing Rayfin docs as `list_docs`, `search_docs`, `get_doc`, and `discover_packages` tools. |
| [`@microsoft/rayfin-docs`](/docs/reference/cli/docs#how-docs-are-discovered) | Tool | Docs indexing and discovery library behind the CLI and MCP server. Merges installed package docs via the `rayfinDocs` `package.json` convention. |
| `@microsoft/rayfin-guide` | Guide | The cross-cutting builder guides that `rayfin docs` and the MCP server serve offline. |
