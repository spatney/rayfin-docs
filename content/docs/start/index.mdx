Rayfin runs the same project two ways: self-hosted on Docker (**Rayfin Local**) or as a
managed **Fabric app** on Microsoft Fabric. Both modes share the same CLI, SDK, and
data-modeling workflow, so nothing you build locally has to change when you deploy.

If you read only one page in this section, read the [Quickstart](/docs/start/quickstart) —
it goes from an empty terminal to a running app in three commands.

## Set up your machine

- **[Installation](/docs/start/installation)** — install Node.js 20+, Docker, and the
  GitHub CLI on Windows, macOS, or Linux.
- **[Quickstart](/docs/start/quickstart)** — scaffold a project with
  `npm create @microsoft/rayfin@latest` and have it running in minutes.

## Build locally

- **[Project structure](/docs/start/project-structure)** — the `rayfin/` folder,
  `rayfin.yml`, and how entity classes become a database schema.
- **[Local development](/docs/start/local-development)** — run the Docker stack, apply
  schema changes, and stop or reset it.

## Ship to Microsoft Fabric

- **[How Rayfin runs](/docs/start/how-rayfin-runs)** — what changes between Rayfin Local
  and a Fabric app: architecture, authentication, and database dialects.
- **[Deploy to Fabric](/docs/start/deploy-to-fabric)** — enable the tenant setting, create
  a Fabric data app, and deploy with `rayfin login` and `rayfin up`.

## Next
