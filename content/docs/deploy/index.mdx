Deploying ships a Rayfin project to a managed **Fabric app**. The deploy workflow syncs backend settings, applies schema changes, builds and uploads static assets, and records the Fabric target.

```bash
npx rayfin login
npx rayfin up
npx rayfin up status
```

Use [Develop locally](/docs/start/develop-locally) for the inner loop. `npm run dev` runs `rayfin dev` and never publishes static content; `rayfin up` publishes a production build.
