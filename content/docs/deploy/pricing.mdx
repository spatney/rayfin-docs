---
title: Capacity and billing
description: Learn which Fabric services behind a Rayfin app consume capacity units and which deployment operations have no separate Rayfin charge.
---

A Rayfin Fabric app runs on Microsoft Fabric capacity. There are no separate Rayfin charges; you pay for the Fabric Capacity Units consumed by the underlying services.


## How billing works

Fabric uses Capacity Units (CUs). Operations performed by the services behind your Fabric app consume CUs from the capacity assigned to the workspace. Rayfin does not add a separate billing meter.

Use the Fabric Capacity Metrics app to see actual consumption by workspace, item, operation, and time window. The CLI cannot estimate your bill from project files because usage depends on live traffic, queries, storage, and build/deploy frequency.

## What consumes capacity

| Service | Operations that consume capacity | Billing meter |
| --- | --- | --- |
| SQL Database | Queries, writes, schema objects, transaction logs, and allocated storage. | SQL database usage and SQL storage. |
| GraphQL API | Query and mutation processing through the Fabric API for GraphQL. | API for GraphQL Query Capacity Usage CU. |
| OneLake static content | Writes during static deployment, reads while serving assets, and stored bytes. | OneLake read, write, and storage meters. |

One Fabric CU equals 0.383 SQL database vCores for SQL Database capacity accounting.

## What does not add a Rayfin-specific charge

- Rayfin WebService routing.
- Fabric brokered auth session handling.
- Running `rayfin up` itself, beyond the SQL and OneLake operations it triggers.
- Running `rayfin dev`, beyond the Fabric backend operations your app performs.


## Capacity readiness and trials

A workspace must have usable Fabric capacity before a Rayfin item can be created or updated. During first deploys, `rayfin up` can help prepare capacity when the account has permission and the tenant allows it:

- Existing workspace capacity is reused when it is usable.
- A selected capacity can be assigned with `--capacity-id`.
- Eligible accounts may start or reuse Fabric trial capacity.
- Some assignments require interactive confirmation or `--yes`.

See [Deploying with rayfin up](/docs/deploy/rayfin-up#prepare-workspace-capacity) for the deploy-time readiness flow and exact error messages.

## Monitor usage

Use the [Microsoft Fabric Capacity Metrics app](https://learn.microsoft.com/fabric/enterprise/metrics-app) to monitor usage by item and operation.

```prompt title="Check capacity usage for my Rayfin app"
Help me identify which Fabric capacity my Rayfin app uses. Read rayfin/.deployments.json, run `npx rayfin up status --json`, and tell me which app operations consume capacity: SQL Database, GraphQL API calls, and static content reads or writes. Point me to the Fabric Capacity Metrics app for actual usage numbers.
```
