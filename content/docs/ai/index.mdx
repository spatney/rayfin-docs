These docs are designed to be read by coding agents, not just by people. Everything a
human can read on this site, an agent can fetch as clean Markdown — no HTML parsing, no
navigation chrome, no JavaScript.

## The fastest way to start

```prompt title="Give your agent Rayfin knowledge"
Read https://rayfin.ai/llms.txt to learn what the Rayfin documentation covers, then read
https://rayfin.ai/docs/ai/rules.md and https://rayfin.ai/docs/reference/known-limitations.md
before writing any Rayfin code.

Every page on that site is available as raw Markdown by appending .md to its URL — for
example https://rayfin.ai/docs/data/querying.md. Fetch the specific pages you need as you
go rather than guessing at APIs.
```

## Site docs versus project docs

There are two ways an agent can get Rayfin documentation, and they serve different needs.

| | This site | `rayfin docs` / MCP server |
| --- | --- | --- |
| Source | Published documentation | The packages installed in your project |
| Versioning | Latest published | Locked to your `node_modules` |
| Access | Any HTTP client | Requires a Rayfin project on disk |
| Best for | Learning, planning, agents without repo access | Exact API details for the version you are on |

Use both. This site teaches the model how Rayfin works; the MCP server confirms the exact
signatures for the version installed in the project being edited.
