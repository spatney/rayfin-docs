Every page on this site exists in two forms: rendered HTML for people, and raw Markdown
for machines. They are generated from the same source, so they never drift.

## Markdown mirrors

Append `.md` to any documentation route.

```bash
curl https://purple-grass-01682270f.7.azurestaticapps.net/docs/data/querying.md
```

| Page | Markdown mirror |
| --- | --- |
| `/docs` | `/docs.md` |
| `/docs/data/querying` | `/docs/data/querying.md` |
| `/docs/reference/cli/up` | `/docs/reference/cli/up.md` |

Mirrors are served as `text/markdown` with `Access-Control-Allow-Origin: *`, so they can be
fetched from a browser-based agent as well as from a server.

### Frontmatter

Each mirror opens with a YAML block identifying the page:

```yaml
---
title: "Querying data"
description: "Read records with the type-safe GraphQL client."
url: https://purple-grass-01682270f.7.azurestaticapps.net/docs/data/querying
markdown_url: https://purple-grass-01682270f.7.azurestaticapps.net/docs/data/querying.md
section: data
product: Rayfin
sdk_version: 1.34.0
source: data/querying.mdx
---
```

`sdk_version` is the `@microsoft/rayfin-*` version the page was written against. Use it to
decide whether to double-check a signature against the
[MCP server](/docs/ai/mcp-server) for the version installed in the project you are editing.

## `/llms.txt`

[`/llms.txt`](/llms.txt) is a compact index: what Rayfin is, how to read these docs, and
every page with a one-line description. It is the right first fetch — roughly one page of
text instead of the whole corpus.

```bash
curl https://purple-grass-01682270f.7.azurestaticapps.net/llms.txt
```

## `/llms-full.txt`

[`/llms-full.txt`](/llms-full.txt) is every page concatenated into one file, each with its
frontmatter, separated by `---`. Fetch it when you want the complete corpus in a single
request — for example when building an embedding index.

```bash
curl https://purple-grass-01682270f.7.azurestaticapps.net/llms-full.txt
```

## `/AGENTS.md`

[`/AGENTS.md`](/AGENTS.md) at the site root is a short operating brief: what Rayfin is, how
to read these docs, what to read before writing code, and a link to every page. Agents that
look for a root `AGENTS.md` by convention will find it.

## Faithfulness

Content is authored so that the Markdown mirror loses nothing:

- Callouts are GFM alerts (`> [!WARNING]`), not components.
- Diagrams are ` ```mermaid ` fences.
- Prompt cards are ` ```prompt ` fences — the prompt text you see on the page is the exact
  text in the Markdown.
- Every code fence is labelled with a language and, where relevant, the file it belongs in.

A build-time check enforces that every rendered route has a valid Markdown mirror, so a
page cannot ship HTML-only.

## Discovery

- [`/sitemap.xml`](/sitemap.xml) lists every HTML page **and** every Markdown mirror.
- [`/robots.txt`](/robots.txt) allows crawlers and points at the sitemap.
- Every HTML page declares its mirror via `<link rel="alternate" type="text/markdown">` and
  a canonical URL.
