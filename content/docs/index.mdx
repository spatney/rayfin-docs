Rayfin is a backend platform for TypeScript developers. You define your data model as
decorated TypeScript classes, and Rayfin generates the database schema, REST and GraphQL
APIs, type-safe clients, authentication, and static hosting for your frontend.

```typescript title="rayfin/data/Todo.ts"
import { entity, uuid, text, boolean, authenticated } from '@microsoft/rayfin-core';

@entity()
@authenticated('*', { policy: (claims, item) => claims.sub.eq(item.user_id) })
export class Todo {
  @uuid() id!: string;
  @text({ max: 200 }) title!: string;
  @boolean({ default: false }) isCompleted!: boolean;
  @text({ max: 128 }) user_id!: string;
}
```

That class becomes a table, a GraphQL API, a typed client, and a row-level security
policy. One command deploys all of it.

```bash
npx rayfin up
```

> [!NOTE]
> Rayfin supports TypeScript as the only language for data models, client code, and
> application logic.

## Two ways to run

| | **Rayfin Local** | **Fabric app** |
| --- | --- | --- |
| What it is | Self-hosted backend stack | Managed service on Microsoft Fabric |
| Authentication | Entra ID, email and password | Fabric SSO (Entra ID) only |
| Database | MSSQL, PostgreSQL | MSSQL only |
| Infrastructure | You host it (Docker, VMs, any cloud) | Fabric manages hosting, scaling, networking |

Both modes share the same SDK, CLI, and data-modeling workflow. Start locally, then deploy
to Fabric when you want a managed service — or stay self-hosted.

See [How Rayfin runs](/docs/start/how-rayfin-runs) for the full comparison.
